## 内容编辑入口

进入：

`source/public/网站内容`

主要目录：

```text
网站内容/
├── 首页/
├── 作品/
│   └── _项目模板/
├── 经历/
│   └── _经历模板/
└── 联系/
```

规则：

- 作品文件夹名称就是网站作品标题。
- 经历文件夹名称可以直接使用年份。
- 以下划线开头的模板不会展示。
- 图片和视频按 `01、02、03` 编号排序。
- 同编号 `.txt` 是对应画面说明。
- 预览或发布前会自动扫描目录并生成内容。
